# OpenRelay brand assets

| File | Use |
|---|---|
| `icon.svg`, `icon-512.png`, `icon-192.png` | App icon (rounded square, dark background) |
| `mark.svg` | Mark alone on a transparent background, for light backgrounds |
| `logo.svg`, `logo.png` | Horizontal lockup: mark plus wordmark |

Colors: violet `#A259F7` → blue `#5FA8E8` → teal `#2EE6C8` on navy `#060B14`. The wordmark is Plus Jakarta Sans ExtraBold (SIL OFL 1.1), converted to outlines, so no font is needed to render it.

The Android launcher icon (`android/app/src/main/res/drawable/ic_launcher_*.xml`) is the same mark on the 108 dp adaptive grid.
